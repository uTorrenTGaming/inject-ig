Manual de Operações
Guia tático sobre o funcionamento das ferramentas e fluxo de injeção.
1. O que cada aba/menu faz?
  • Terminal: Linha de comando nativa. Digite ajuda para ver comandos como injetar ou core.
  • Injeção: Seu C2 local. Selecione o diretório de um projeto (React, Vue, Node) e implante o payload remoto.
  • Arquivos (Vault): Repositório que lista os alvos infectados. Contém o Monitor (Telemetria da JVM).
  • Ferramentas: Scanners passivos automatizados (Headers, Cookies, Stack) que não deixam rastros pesados.
  • Exploits: Ataques ativos (Deep Recon, SQLi, XSS) disparados do Motor Java contra o servidor alvo.
  • Relatórios: Central de exportação JSON de vulnerabilidades.
  • Mobile: Radar ADB e instalador. Compila projetos via Capacitor e injeta via USB no Android.
2. Como as Ferramentas (Scanners) funcionam?

As Ferramentas são baseadas em varreduras passivas. Quando você seleciona uma ferramenta e clica em "Executar Módulo", a API Java puxa cabeçalhos HTTP, Cookies e analisa assinaturas WAF/CMS. Elas servem para fazer o mapeamento da topologia do alvo antes de um ataque.

3. Como os Exploits (Deep Recon) operam?

O módulo de Exploits é ofensivo. Ele injeta payloads e malformações em endpoints (LFI, RCE, SSRF). Clicar em "Lançar Ataque" ativa threads paralelas no Core Engine que bombardeiam a rede em busca de brechas, gerando alertas vermelhos no log caso uma CVE crítica ou Injection seja detectada e refletida.

4. Qual é o fluxo correto de Injeção?
  1. Abra a aba Injeção e selecione a pasta base do alvo (React/HTML).
  2. Isso adiciona o payload invisível e armazena o alvo na aba Arquivos.
  3. Vá em Monitor e veja os acessos ("Time-Travel") entrarem ao vivo no "Radar".
  4. Se o alvo for um App, vá na aba Mobile, escaneie as portas USB e clique em Compilar e Instalar para criar um APK infectado diretamente pro celular.

O inject-ig é uma ferramenta desenvolvida estritamente para propósitos educacionais, acadêmicos e auditorias de segurança autorizadas (Red Teaming / Penetration Testing).
