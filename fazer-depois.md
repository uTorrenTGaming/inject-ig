# 🚀 Ideias e Features Futuras (Fazer Depois)

Este documento contém ideias de alto valor para serem implementadas no **inject-ig**, com o objetivo de aumentar o engajamento e fornecer ferramentas de produtividade e segurança de ponta.

---

### 1. 🧠 Assistente de IA 100% Local (Modo Fantasma)
**Conceito:** Integrar um modelo de Inteligência Artificial que roda inteiramente no hardware do usuário (ex: Llama.cpp ou Ollama).
* **Por que implementar?** O usuário teria um assistente privado que não envia nenhum dado para a internet. Perfeito para analisar códigos de exploits, gerar payloads ou resumir documentos confidenciais com privacidade absoluta, combinando com o foco de processamento offline do sistema.

### 2. 🌍 Radar de Tráfego de Rede (Dashboard Visual 3D)
**Conceito:** Um painel interativo (estilo globo 3D ou radar) que rastreia conexões de rede do computador em tempo real, usando GeoIP para mapear destinos.
* **Por que implementar?** Ferramentas visuais de tráfego de rede trazem uma estética hacker imersiva. É útil para detectar spywares, telemetria invasiva de outros apps e impressionar visualmente quem está usando o console.

### 3. 🕵️ Painel de OSINT (Inteligência de Fontes Abertas)
**Conceito:** Módulo de investigação automatizada. O usuário digita um E-mail, Número de Telefone ou Username, e o sistema varre APIs públicas e registros de vazamentos (Dark Web/Have I Been Pwned).
* **Por que implementar?** Automatiza a criação de "Dossiês" (foto de perfil, redes, senhas vazadas). Uma ferramenta impecável para Red Teaming e investigações rápidas.

### 4. 🔒 Cofre de Criptografia Militar (Drag & Drop)
**Conceito:** Interface elegante onde o usuário arrasta arquivos sensíveis para a tela e o sistema aplica criptografia AES-256 localmente.
* **Por que implementar?** Traz uma forte sensação de controle e segurança sobre os próprios dados. Requerer uma senha ou um Pendrive (como chave de hardware) para desbloquear os arquivos adiciona muito valor ao produto.

### 5. ⚡ Criador de Automações Visuais (Estilo "Apple Shortcuts")
**Conceito:** Um ambiente "Automator" onde o usuário pode arrastar blocos visuais para criar rotinas complexas sem precisar saber programar (ex: `[Ler PDF] -> [Extrair E-mails] -> [Enviar para Varredura] -> [Salvar Relatório]`).
* **Por que implementar?** Reduz a curva de aprendizado e empodera o usuário a criar fluxos de auditoria personalizados rapidamente.

### 6. 📱 Espelhamento e Análise Forense Mobile (Raio-X)
**Conceito:** Evolução da aba "Mobile". Ao invés de apenas injeção, permitir uma análise profunda via cabo USB, extraindo dados invisíveis, logs do sistema, bateria real e aplicativos ocultos de dispositivos Android/iOS.
* **Por que implementar?** Fornece capacidades de forense digital premium diretamente de uma interface amigável.
